ออกแบบappสำหรับงานUdon Thani International Horticultural Expo 2026 โดยอยากให้มีหน้าแรกเป็นข้อมูลทั่วไปของงาน อย่างเช่น ไฮไลต์ประจำวันแบบเลื่อนได้ ข่าวสาร ข้อมูลโซนคร่าวๆ 

มีเมนูล่าง อย่างเช่น ปุ่มสแกนต้นไม้เพื่อดูข้อมูลและปุ่มสนใจซื้อต้นไม้ หน้าmapที่สามารถเลื่อนดูแต่โซนได้
ส่วนการสแกนต้นไม้จะเด่งหน้าข้อมูลต้นไม้ ซึ่งจะสามารถใช้aiของappในการแปลภาษาและบรรยายออกเสียง ซึ่งหากผู้ดูสนใจต้นไม้นั้น ส่วนล่างสามารถกดเข้าไปดูที่หน้าร้านต้นไม้ชนิดนั้นได้
ให้ป้ายประจำงานเป็นheadline ต่อมาเป็น ไฮไลต์ประจำงาน หรือประจำวัน ที่สามารถเลื่อนได้เพิ่มการทำไฮไลต์โซนที่นิ้วชี้ และโซนที่เราอยู่ในปัจจุบัน เพราะต้องมีระบบmapที่เมื่อสะแกนต้นไม้แต่ละโซนระบบจะส่งข้อมูลผู้ชม ต้นไม้ และโซนที่ชม กลับเข้าฐานข้อมูล
อยากให้เป็นหน้าmarketplaceรวมการจัดวางแบบecomerมืออาชีพ เป็นหน้า1 แต่ถ้าคนสแกนต้นไม้แล้วสนใจซื้อต้นไม้นั้นแล้วกดเข้าชมร้านจะส่งไปที่หน้าร้านของต้นไม้นั้นก่อน แต่ก็ยังสามารถกลับมาดูที่หน้าหลักเพื่อดูต้นไม้ชนิดอื่นๆได้ปก ทำให้เหมือนecomercเลย
