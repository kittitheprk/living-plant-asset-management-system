วันที่/เวลา ชื่อผู้ติดต่อ เบอร์โทร Tree ID / ต้นไม้ ประเภทกิจกรรม มูลค่า สถานะไปป์ไลน์ บันทึกทีมงาน อัปเดต

สำรองข้อมูล & ป้องกันการผูกติด (Data Portability)

ส่งออกฐานข้อมูลทั้งหมดเป็น JSON หรือ CSV ตามข้อกำหนดใน TOR เพื่อให้หน่วยงานเป็นผู้ถือครองข้อมูล 100%

REST API Endpoints สำหรับเชื่อมต่อแอปพลิเคชัน

GET /api/v1/plants ➔ รายการต้นไม้ที่เผยแพร่ (Tree ID, พิกัด, ข้อมูลพฤกษศาสตร์)

GET /api/v1/plants/:tree_id ➔ ข้อมูลต้นไม้รายต้นตามรหัสสแกน QR Code

POST /api/v1/observations ➔ บันทึกผลการสำรวจสุขภาพและขนาดภาคสนาม

POST /api/v1/leads ➔ บันทึกความสนใจและการสั่งซื้อจากแอปผู้เข้าชม

GET /api/v1/zones ➔ ผังขอบเขต 7 โซน GeoJSON และเป้าหมายสำรวจ
